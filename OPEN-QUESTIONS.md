## Решения Димы

### Р2. Фото: CDN Kaspi или своё хранилище
- Что нужно: решить, остаёмся на CDN Kaspi или включаем зеркалирование.
- Зачем: если Kaspi начнёт резать хотлинк, фото пропадут. И второе - скорость: фото Kaspi - тяжёлые JPEG (750 px весит 160-345 КБ), CDN Kaspi отдаёт их с кэшем всего 10 минут. На карточке модели это главное фото первого экрана, и LCP на мобильном из-за него 3,3-3,6 с при цели 2,5 с (Lighthouse mobile, см. docs/DECISIONS.md). Главная, категория и гайд в норму укладываются.
- Сейчас: фото с CDN Kaspi через srcset. Скрипт `scripts/mirror-media.ts` готов, по умолчанию выключен. Замер 2026-10-27: главное фото 750 px - 34 КБ WebP вместо 160-345 КБ JPEG Kaspi; LCP карточки Classic/Tiddly с зеркалом - 2,27-2,48 с (Lighthouse simulate) и 1,78-1,85 с (реальный троттлинг), без зеркала - 3,3-3,6 с.
- Варианты:
  - зеркалить только главное фото каждой расцветки (`--scope=first`, 48 фото, ~6 МБ) прямо в сборку: хватает для LCP, отдельное хранилище не нужно, в CI +30 с на скачивание;
  - зеркалить все фото (`--scope=all`, ~600 фото, 100+ МБ) - нужно хранилище (Cloudflare R2 / Vercel Blob) на аккаунте Эммы.
- Разблокирует: LCP карточки в пределах 2,5 с и независимость от хотлинка Kaspi. Включается: `pnpm tsx scripts/mirror-media.ts --scope=first` перед сборкой и `MIRROR_MEDIA=1` в env сборки.

### Р3. Откуда запускать синхронизацию (нужен пробный прогон)
- Решение Димы (2026-10-27): сейчас - бесплатно и не на компьютере Димы, позже всё переезжает на VPS.
- План:
  1. GitHub Actions (бесплатно). После создания репозитория запустить вручную workflow «Проба доступа к Kaspi с раннера» (`.github/workflows/kaspi-probe.yml`). Сам запустить не могу - нет репозитория.
  2. Если Kaspi режет раннеры GitHub - Cloudflare Worker по cron (бесплатный тариф): тянет Kaspi и коммитит данные через GitHub API. IP у Cloudflare тоже не казахстанский, пройдёт ли - [непроверено], проверю пробой, когда будет аккаунт (Д2).

- Сейчас: с моей машины в Казахстане синхронизация работает без браузера; workflow `sync.yml` готов (цены - каждый час, полный срез - ночью, коммит только при изменениях).
- Разблокирует: стабильную синхронизацию на проде.
